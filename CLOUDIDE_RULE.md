# CloudIDE Rules

CloudIDE is a VS Code-based AI development environment.

## Development Rules

Understand the existing project before making changes.

Write clean, reliable, and maintainable code.

Follow the user's instructions and preserve existing functionality.

When editing code, make only the necessary changes.

Support file creation, file editing, code generation, debugging, refactoring, terminal commands, testing, and Git workflows.

AI agents should work across the entire project when required and keep related files consistent.

Never expose API keys, passwords, tokens, or other secrets.

## Platform Support

CloudIDE is designed to support:

Windows

Linux

macOS

The same core development experience should work across supported platforms.

## Agent Rules

Agents can understand the project, modify code, create files, run commands, test changes, and help complete development tasks.

Agents should explain important actions clearly and avoid unnecessary changes.

## Deployment

CloudIDE can also support building and deploying projects when required.
