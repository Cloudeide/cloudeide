# CloudIDE Agents

## Purpose

CloudIDE is a VS Code-based development environment with powerful AI coding agents.

The purpose of the CloudIDE Agent is to help developers understand, create, edit, refactor, debug, test, and manage software projects directly inside CloudIDE.

The agent works with the developer's complete project, not only with individual code snippets.

### Agent Harness

CloudIDE uses an agent harness to connect the AI model with the development environment and available tools.

The harness can coordinate model interaction, project context, file access, code search, file editing, terminal execution, testing, Git workflows, tool calls, task execution, and result verification.

### Model Support

CloudIDE is designed to support modern coding models and agent workflows.

Model capabilities may include code understanding, large project context, tool use, multi-step reasoning, file editing, terminal interaction, and agent workflows.

Specific model capabilities depend on the model and CloudIDE configuration.

### VS Code Foundation

CloudIDE is built as a fork of the VS Code codebase.

CloudIDE keeps the familiar development experience of VS Code while adding AI-powered development capabilities.

The foundation includes the code editor, file explorer, integrated terminal, extensions, source control, debugging tools, and developer tooling.

CloudIDE extends this foundation with project-level AI agents and AI-assisted development workflows.

### Developer Control

The developer remains in control of the project.

The agent follows developer instructions.

The agent respects project structure.

The agent explains important changes.

The agent avoids unnecessary modifications.

The agent protects sensitive information.

The agent preserves unrelated changes.

The agent clearly reports completed work.

The agent never claims something was done when it was not.

### Security

The agent must treat API keys, passwords, access tokens, private keys, environment secrets, and authentication credentials as sensitive information.

Secrets should not be intentionally exposed in source code, logs, commits, or generated responses.

CloudIDE may also support deployment workflows.

### Goal

The goal of CloudIDE Agents is to give developers a powerful AI-assisted development environment.

CloudIDE helps developers understand code, create files, edit files, modify multiple files, write code, refactor code, debug problems, run commands, test applications, review changes, work with Git and GitHub, build software, and ultimately ship it.

CloudIDE combines the familiar VS Code development experience with powerful AI agent capabilities.
